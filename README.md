# MYTHBUSTERS2
The main idea behind MYTHBUSTERS is to give people a fun way to test their common sense and see if they can actually tell the difference between a genius productivity tip and a viral rumor. It uses a flashcard style to teech users what’s actually worth trying in the real world and what is just a total waste of time.

The app starts with a simple Welcome Screen that explains the rules before you hit the "Start" button.
 Once you're in the quiz, you’ll see different "hacks" and have to decide if they are reel or just a myth. I made sure to include immediate feedback for every single answer, so you’ll know right away if you’re a genius or if you’ve been fooled. It's meant to be super intuitiv so anyone can pick it up and start playing without needing a manual.
 
For the progamming side of things, I used a loop to cycle through the question set and keep track of your score as you go. When you finish the last card, the app calculates your total and shows you a final score screen with a personalized message based on how well you did. There is also a "Review" button I added because I think it’s important for users to actually read the explanations for the ones they got rong.
